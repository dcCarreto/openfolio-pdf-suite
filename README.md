# OpenFolio PDF Suite

Suite completa e open source de manipulação de PDF, 100% local, sem paywall.

## Requisitos

- Python 3.10 ou superior

## Como instalar

```bash
git clone https://github.com/dcCarreto/openfolio-pdf-suite.git
cd openfolio-pdf-suite
pip install -e .
```

## Como rodar

```bash
python main.py
```
